🎨 Color Studio

A clean and interactive color generator built with **HTML, CSS, and vanilla JavaScript**.

Color Studio generates random colors, displays their HEX, RGB, and HSL values, and lets you copy HEX codes or revisit recently generated colors.

 ✨ Features

- 🎨 Generate random HEX colors
- 👁️ Live color preview
- 🔢 HEX, RGB, and HSL values
- 📋 Copy HEX color codes
- 🕘 Recent color history
- 🔄 Click previous colors to restore them
- ✨ Smooth color transitions and subtle animations
- 📱 Responsive design for desktop and mobile
- ⚡ No external libraries or frameworks
- 🌐 Can be deployed using GitHub Pages
